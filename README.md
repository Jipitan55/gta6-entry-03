PORTO VERDE — Sunset Heist is an original 3D open-world crime game built with Three.js that runs entirely offline with zero network requests. Step into the shoes of getaway driver Danny "Dash" Cole, taking on high-stakes jobs for your fixer Mara Voss across a sun-soaked procedural coastal city. Explore a 9x9 block metropolis on foot or behind the wheel, outrun pursuing police, master arcade vehicle physics, and complete a thrilling 3-mission story chain.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in your browser.

## Controls

- **WASD / Arrows**: Move / Drive
- **Shift**: Run
- **E**: Enter / Exit vehicle
- **F**: Punch
- **Mouse Click**: Shoot
- **Mouse Drag**: Orbit camera
- **P / Esc**: Pause menu
- **M**: Mute audio

## Features

- Fully procedural 9x9 block city with roads, buildings, beach, and pier.
- Traffic AI and reactive pedestrians who flee danger.
- Stealable cars with arcade driving physics.
- 0–5 star wanted system with pursuing police cars and arrest/busted states.
- Melee combat and pistol shooting.
- 3-mission story chain with cash rewards and ending sequence.
- HUD with minimap, health, cash, wanted stars, and active objectives.
- LocalStorage game saving and WebAudio sound effects.
